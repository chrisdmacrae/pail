No pail.json, so Pail serves the files as they are. Add one beside your app for functions, rewrites and redirects:

{
  "functions": { "api": "./server/api.js" },
  "routes": [
    { "path": "/api/*", "to": "function:api" },
    { "path": "/*", "to": "./dist", "fallback": "index.html" }
  ]
}
