# Icons

Twelve 24px line icons: 1.75 stroke, round caps and joins. These files are drawn in ink `#1e1c17` for use as images on Day grounds; in UI use the `Icon` component, which draws the same paths in `currentColor`.

- `pail.svg` — Pail itself / a pail.
- `plus.svg` — New pail.
- `terminal.svg` — pail-cli source.
- `git.svg` — every git host (GitHub, GitLab, Bitbucket, Gitea, Forgejo). No provider logos.
- `upload.svg` — Upload source; uploading.
- `folder.svg` — the drop zone at rest.
- `copy.svg`, `check.svg` — copy a command / copied.
- `external.svg` — open a pail's URL.
- `globe.svg` — a domain or hostname.
- `redeploy.svg` — Redeploy.
- `trash.svg` — Remove pail.
