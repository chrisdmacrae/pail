# Brand

- `pail-mark.svg` — the mark (32×32): a pail's handle, rim and tapered body in ink `#1e1c17`, filled to the line in pail yellow `#f2b134`. For Day (`surface`, `surface-raised`).
- `pail-mark-reversed.svg` — the same in ink `#f2ede2`, fill `#f4bd4c`. For Night grounds.
- `pail-wordmark.svg` — mark + lowercase "pail" (Bricolage Grotesque Bold, outlined), ink `#1e1c17`. Day.
- `pail-wordmark-reversed.svg` — the same in `#f2ede2`. Night.

Inline UI uses the TopBar's mark, drawn in `currentColor` with the fill bound to `pail`. Clear space = the rim's height above the handle, on every side; minimum 16px tall. Never on a pail fill.
