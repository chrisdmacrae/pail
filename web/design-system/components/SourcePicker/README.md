# SourcePicker

Step one of a new pail: where is the site? Seven tiles — pail-cli, Upload, and the five git hosts — as a single-choice radio group. The selected tile takes `water-soft` with a `water-ink` edge. Provider names are plain type with the shared `git` icon; never their logos.

- Provide: `value` + `onChange` (or `defaultValue`); `sources` only to hide hosts that aren't connected.
- After a pick, show exactly one next thing: a Command (cli), a DropZone (upload) or a repo list (git).
