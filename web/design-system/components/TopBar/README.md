# TopBar

The only chrome Pail has: the mark and lowercase wordmark on the left, the host it's running on in mono, and the one primary action — "New pail" — on the right. No nav, no account menu, no avatar: there are no accounts.

- Provide: `host` (e.g. `pail.lan`), `onNew`; `children` replaces the right side on a pail's own page (e.g. a Redeploy button).
