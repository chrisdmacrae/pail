# Command

The copyable one-liner — the CLI path into Pail and the thing CI pastes. One command per block; a `comment` line above it says what it does in plain words. The Copy button flips to "Copied" for 1.6s.

- Provide: the command as `children` (a string, no `$`), optional `comment`.
- Keep commands real and short: `pail up ./dist`, not a wall of flags.
