# Icon

Twelve 24px line icons, 1.75 stroke, round caps, drawn in `currentColor` — so they take the text colour they sit in. Use them beside a word, never instead of one (except ghost row actions, which carry an `aria-label`).

- Provide: `name`, optional `size` (16 in small buttons, 18 default, 20–28 in tiles and the drop zone), `label` only when the icon stands alone and means something.
- Git hosts share the one `git` glyph; Pail never draws a provider's logo.
